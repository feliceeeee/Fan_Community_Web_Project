# Clash of BaNG

**Clash of BaNG** is a fan community website concept for a fictional dark fantasy tactical game inspired by the gameplay elements and character designs of **Clash of Clans** and **Mobile Legends: Bang Bang**. The website combines strategic base-building and troop mechanics with fast-paced hero combat in a dark fantasy-themed community experience.

## Project Overview

This project was developed as an interactive community website that presents the fictional **Clash of BaNG** universe through character showcases, game updates, community history, and a clan registration system. The website is designed with a dark fantasy visual theme and responsive layouts for desktop, tablet, and mobile devices.

## Main Features

* **Home Page** — Features the game introduction, an auto-rotating game update carousel, popular troops, community information, and beginner strategy tips.
* **Gallery Page** — Showcases artwork from the Clash of BaNG universe, including troop, hero, and special artwork.
* **Troops Page** — Displays featured fusion troops with interactive hover effects that reveal their stats, damage type, and special abilities.
* **About Page** — Presents the community's fictional origin, founders, and historical timeline from 2018 to 2026.
* **Register Page** — Provides a clan registration form with comprehensive client-side validation, inline error messages, success/error toast notifications, and automatic redirection after successful registration.
* **Responsive Design** — Adapts the navigation and page layouts for desktop, tablet, and mobile screen sizes.
